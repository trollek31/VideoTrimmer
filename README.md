# Video Trimmer — Portable Windows

Простой Windows-редактор для обрезки начала и конца MP4.

## Запуск

**Скачать ZIP → распаковать → запустить `VideoTrimmer.exe` → работать.**

Ничего устанавливать не нужно.

Внутри portable-архива лежит `runtime\ffmpeg-runtime.zip` с полным FFmpeg runtime.
При первом запуске приложение автоматически достаёт из него `ffmpeg.exe`, `ffprobe.exe`,
`ffplay.exe` и нужные DLL во временную папку Windows.

## Возможности

- MP4 H.264/H.265 и обычные AAC/другие аудиодорожки.
- Обрезка начала и конца.
- Перетаскивание MP4 в окно.
- Большой предпросмотр.
- Таймлайн с двумя маркерами.
- Ввод времени `HH:MM:SS.mmm`.
- `Space` — воспроизведение/пауза.
- `Ctrl+O` — открыть.
- `Ctrl+S` — сохранить.
- **Без перекодирования** — исходный поток копируется без повторной компрессии.
- **Точная обрезка** — покадровая точность с перекодированием H.264/AAC.
- Сохранение через временный `.part.mp4` перед финальным переименованием.
- Корректные русские пути, пробелы, скобки и спецсимволы.
- Приложение не позволяет уменьшить окно настолько, чтобы интерфейс обрезался.

```text
VideoTrimmer_Windows/
├── VideoTrimmer.exe
├── README.md

├── THIRD_PARTY_NOTICES.txt
└── runtime/
    └── ffmpeg-runtime.zip
```

## Сборка разработчиком

В PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

Скрипт скачивает FFmpeg runtime только во время **сборки**, а затем кладёт его внутрь
финального portable-пакета. Конечному пользователю интернет не требуется.

## Лицензии

В проекте используется FFmpeg. Перед публичной публикацией приложения необходимо
сохранить соответствующие лицензии и NOTICE выбранной FFmpeg-сборки.
